# What may be shared, and what may not

| File(s) | Source | Share the skill with it? |
|---|---|---|
| `fonts/Anton-Regular.ttf` | Google Fonts, SIL Open Font License 1.1 (`fonts/OFL.txt`) | Yes, with `OFL.txt` |
| `textures/grain.png` | Made in code for this skill | Yes |
| `plates/*.jpg` (mustard, walnut, emerald, teal) | Generated by the user with a free image tool for the chai demo (same files as in `library/plates/`) | Yes (the user's own) |
| `library/` (plates, props, sources, baked scenes) | Generated by the user with free image tools for the chai demos V1, V3, V4; cut out locally | Yes (the user's own) |
| `templates/starter/assets/img/demo_coin.png` | Drawn in code | Yes |
| `sfx/*.mp3` (whoosh, swoosh, boom, click, ding, riser) | **Made in code** by `scripts/make_sfx.sh` (ffmpeg maths, no samples) | Yes |
| `music/` | **Not included.** Bring your own dark track + calm track (or none: SFX only) | — |
| `examples/chai_v4/assets/audio/*` | The 8 code-made SFX + **silent placeholders** for `voiceover.mp3` and `bgm_v4_mix.mp3` (the original voice and music bed were removed) | Yes |
| `examples/chai_v4/assets/img/*` | Generated by the user for the chai demo | Yes (the user's own) |

The reference reels, contact sheets and the old skill versions live **outside** this folder
(`../reference_videos/`, `../reference_sheets/`, `../history/`) on purpose: the reels are another creator's
work and must never be shipped with the skill.

**This copy is already shareable:** all audio is made in code or silent; no third-party music or voice is inside.
