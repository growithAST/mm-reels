# MM Style Reels: Claude skill

Make 9:16 tactile science / myth-buster reels (the "chai video" style) with Claude, free and local
(HyperFrames, rembg, whisper.cpp, ffmpeg).

## Use it
1. Open this repo in Claude (desktop app → **Code** tab → choose this folder, or the Claude phone app → **Code** → this repo).
2. Type: `/meanwhile-mayank-style-reels start`
   Claude checks the setup, asks before installing anything, then asks all the reel questions at once.

The skill lives in `.claude/skills/meanwhile-mayank-style-reels/` (start with its `GUIDE.md`).
Phone / computer steps in Hinglish: `steps.md`.
